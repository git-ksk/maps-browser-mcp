# Code of Conduct

## Our standard

`maps-browser-mcp` is an open-source project with a deliberately narrow technical and safety scope. Participation should stay respectful, constructive, and focused on improving the project.

Expected behavior includes:

- treating contributors and users with respect,
- giving technical feedback about the work rather than attacking the person,
- assuming good faith while still reviewing security and safety claims critically,
- respecting privacy and avoiding publication of credentials, private locations, browser profiles, or other sensitive data,
- accepting maintainer decisions about project scope even when a proposal is declined.

Unacceptable behavior includes:

- harassment, threats, discrimination, or targeted insults,
- sexualized or otherwise inappropriate personal conduct,
- doxxing or publishing another person's private information,
- deliberately posting secrets, credentials, private location data, or exploit details in public project spaces,
- sustained disruption, spam, or attempts to bypass moderation or repository safety rules.

## Project scope disagreements

Technical disagreement is welcome. This project intentionally excludes generic browser control, bulk scraping/crawling, review harvesting, CAPTCHA bypass, stealth/evasion features, and similar scope expansions described in [CONTRIBUTING.md](CONTRIBUTING.md).

A declined proposal is not a conduct violation. Continue the discussion respectfully or use a fork if you need a materially different project direction.

## Enforcement

Maintainers may edit or remove comments, close or lock discussions, reject contributions, or restrict participation when behavior violates this policy or exposes sensitive information.

For public, non-sensitive moderation concerns, open a minimal issue describing the concern. Do not include private personal information. For abuse that requires private handling, use GitHub's reporting mechanisms rather than publishing sensitive details in the repository.

Security vulnerabilities are handled separately through [SECURITY.md](SECURITY.md) and GitHub Private Vulnerability Reporting.

## Scope

This Code of Conduct applies to repository issues, pull requests, reviews, discussions, and other project-managed collaboration spaces.
